2. SOLUTION: Apply Wrist Compensation at Clearance
================================================================================

MOTION SEQUENCE - Placement on Square X:

         |
         |-------- Lift Motor (M3) rises
         |-------- Wrist Motor (M1) at home angle

         |         Arm at clearance height (≈90°)
         |         Ready to travel
         |
         |
         v         Travel Phase (travelMs duration)
      Travel

                   M3 maintains clearance
                   Arm passes above board
         |
         |-------> Time = compensationStart
         |         Arm is now above destination square
         |
         |
         v         COMPENSATION PHASE ← NEW! ← Solves rotation problem
      [COMP]
      ====X====    M1 (Wrist) rotates to COMPENSATION angle

         |
         |-------> Time = wristStart

         |
         |

================================================================================

Kinematic Configuration at Different Positions:

   M3 ≈ 170°                         M3 ≈ 170°                    M3 ≈ 143°
   M1 ≈ 73°                          M1 ≈ 73°                     M1 ≈ 143°
   
   [M5]                              [M5]                         [M5]
    |                                 |                            |
    M4                                M4                           M4
    /                                 /                            /
   M3                                M3                           M3
   |                                  |                            |
   |                                  |                            |
   M2     (arm carries piece)          M2                           M2
    \                                  \                            \
     M1   (gripper at fixed angle)      M1   (same gripper angle    M1
      |                                  |     but different        |
    ====   ← Piece orientation           |     kinematic config)  ====
  [Grip]                              ====                       [Grip]
                                    [Grip]

Same piece starting orientation (vertical ====)

After complex arm movement and position change:
- Pickup: Piece stays vertical ✓
- Square 1: Piece rotates +12° (clockwise) ✗
- Square 9: Piece rotates +13° (clockwise) ✗

Solution: Rotate wrist while HIGH ABOVE BOARD
- At clearance height (away from board interference)
- Before lowering to board
- Different rotation for each square

9. COMPENSATION APPLICATION FLOWCHART
================================================================================

Start Transfer to Cell
      ↓
Is this a placement move?
(phase == Motion::ToCell)
      ├─ NO → Use normal motion → End
      │
      └─ YES → Continue
             ↓
        Get destination square number
        (pendingSquare: 1-9)
             ↓
        Is square valid?
        (1 ≤ pendingSquare ≤ 9)
             ├─ NO → Use zero compensation → End
             │
             └─ YES → Calculate
                    ↓
                 cellIndex = pendingSquare - 1
                 compensation = wristCompensation[cellIndex]
                    ↓
                 wristAtClearance = home_angle + compensation
                    ↓
                 Constrain to 0-180°
                    ↓
                 Create motion segments:
                 1. Lift to clearance
                 2. Travel to square
                 3. Rotate wrist to compensation angle
                 4. Rotate wrist to final board angle
                 5. Lower to board
                    ↓
                 Execute motion plan → End

10. SUMMARY: THE COMPLETE SOLUTION
================================================================================

PROBLEM:
  Pieces rotate ±5-15° when placed on different board squares
  ↓
ROOT CAUSE:
  Kinematic configuration changes during movement
  ↓
SOLUTION:
  Apply per-square wrist compensation at clearance height
  ↓
IMPLEMENTATION:
  1. Add wristCompensation[] lookup table (9 values)
  2. Calculate compensation angle for each square
  3. Apply rotation at high altitude (clearance height)
  4. Use two-phase wrist motion for smooth adjustment
  ↓
RESULT:
  Pieces arrive ±2-3° rotation (mostly straight!)
  ✓ Game fully playable
  ✓ Professional appearance
  ✓ Backward compatible
  ✓ Easy to calibrate
